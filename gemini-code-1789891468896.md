# Blueprint Arsitektur & Roadmap Integrasi Mail Server dengan Laravel

## 1. Skema Arsitektur Sistem

### A. Lapisan Infrastruktur Jaringan & DNS
*   **IP Server:** 1 Dedicated IP Public (Harus bersih dari blacklist spam).
*   **DNS Records:**
    *   `A Record` -> `mail.domain.net.id` -> [IP Mail Server]
    *   `MX Record` -> `domain.net.id` -> `mail.domain.net.id` (Priority 10)
    *   `TXT` (SPF) -> `v=spf1 mx a ~all`
    *   `TXT` (DMARC) -> `v=DMARC1; p=quarantine;`
    *   `TXT` (DKIM) -> Public key dari OpenDKIM.
    *   `PTR Record` (rDNS) -> [IP Mail Server] di-resolve kembali ke `mail.domain.net.id`.

### B. Lapisan Core Engine (Sistem Operasi)
*   **Database (MySQL/MariaDB):** Menyimpan tabel `virtual_domains`, `virtual_users` (berisi hash password), dan `virtual_aliases`.
*   **MTA (Postfix):** Menangani *routing* dan pengiriman SMTP. Dikonfigurasi untuk mengecek eksistensi domain dan user langsung ke MySQL.
*   **MDA (Dovecot):** Menyimpan email secara fisik ke direktori `/var/vmail/` (format Maildir) dan melayani akses IMAP/POP3.
*   **Security Stack:** OpenDKIM (Digital Signature), SpamAssassin/Rspamd (Anti-spam), Let's Encrypt (Sertifikat SSL).

### C. Lapisan Aplikasi (Laravel)
*   **Dashboard Admin:** Modul CRUD (Create, Read, Update, Delete) yang terhubung ke database `virtual_users` di MySQL. Menambah user di sini akan otomatis membuat email tersebut aktif di Postfix/Dovecot.
*   **Webmail Client:** 
    *   *Receive:* Menggunakan package `webklex/php-imap` untuk menarik email masuk dari Dovecot (localhost:993).
    *   *Send:* Menggunakan konfigurasi `MAIL_MAILER=smtp` bawaan Laravel yang diarahkan ke Postfix (localhost:587).

## 2. Roadmap Implementasi (Fase Berurutan)

### Fase 1: Persiapan Fondasi (Hari 1)
1.  Siapkan VPS/Dedicated Server dengan OS Linux (Ubuntu/Debian) dan IP Statis.
2.  Pastikan penyedia server membuka blokir **Port 25** (Outbound SMTP).
3.  Konfigurasi rDNS pada IP publik agar menunjuk ke `mail.domain.net.id`.
4.  Atur A Record dan MX Record di panel DNS domain utama.
5.  Instal Nginx dan MySQL/MariaDB. Buat skema tabel untuk *Virtual Users*.

### Fase 2: Instalasi Core Mail Engine (Hari 2-3)
1.  Instal Postfix dan konfigurasikan `virtual_mailbox_domains` dan `virtual_mailbox_maps` agar terhubung dengan MySQL.
2.  Instal Dovecot, atur autentikasi *passdb* dan *userdb* menggunakan *query* ke tabel MySQL yang sama.
3.  *Generate* sertifikat Let's Encrypt untuk `mail.domain.net.id` dan pasang di Postfix (`smtpd_tls_cert_file`) serta Dovecot (`ssl_cert`).
4.  Lakukan pengujian internal: Gunakan klien pihak ketiga (Thunderbird) untuk login dan mengirim pesan antar-akun lokal.

### Fase 3: Autentikasi Pengirim (Hari 4)
1.  Instal OpenDKIM. *Generate* kunci privat/publik.
2.  Masukkan kunci publik ke TXT Record DNS (`default._domainkey`).
3.  Konfigurasikan Postfix agar merutekan email keluar (outbound) melewati *milter* OpenDKIM.
4.  Tambahkan SPF dan DMARC Record di DNS.
5.  Uji skor email menggunakan layanan seperti *Mail-Tester.com*. Target skor minimum: 10/10.

### Fase 4: Integrasi Laravel (Hari 5-7)
1.  Inisialisasi *project* Laravel baru.
2.  **Modul Admin:** Buat *Model* dan *Controller* yang terkoneksi dengan database mail server. Buat antarmuka (Blade/Inertia) untuk manajemen akun email.
3.  **Modul Webmail:** Integrasikan `webklex/php-imap`. Buat antarmuka UI untuk *Inbox*, *Sent*, dan *Compose Email*.
4.  Deploy Laravel di belakang Nginx (pada subdomain seperti `app.domain.net.id` atau di dalam `mail.domain.net.id`).

### Fase 5: IP Warming & Produksi (Minggu 2-4)
1.  Mulai kirim email percobaan dalam jumlah kecil (10-20 email/hari) ke berbagai layanan (Gmail, Yahoo, Outlook) untuk membangun reputasi IP.
2.  Pantau log di `/var/log/mail.log` untuk memastikan tidak ada *bounce* atau *rate limit* dari Google.
3.  Tingkatkan volume pengiriman secara bertahap setiap minggunya.
